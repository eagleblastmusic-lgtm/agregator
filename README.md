# Agregator

Faro Employer Discovery Engine — narzędzie do wykrywania firm aktywnie rekrutujących, ustalania ich oficjalnych stron WWW oraz odnajdywania publicznie udostępnionych kanałów współpracy B2B wraz z dowodem źródłowym i oceną pewności.

> Projekt jest w fazie bootstrap/M0. Szczegółowa architektura i plan rozwoju są rozwijane na gałęzi roboczej.
